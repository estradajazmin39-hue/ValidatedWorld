# CLAUDE.md

Read and follow the repository guidance in the root repository agents file, `/AGENTS.md`.

For implementation work, read and update
`/docs/implementation_execution_plan.md`. Implement only its current assignment;
do not skip queued or gated work. A handoff is incomplete until the plan records
the completed evidence and gives the next agent an explicit executable task.

Before completing changes, run the assignment-specific checks and the full
restore, build, and test commands from `/AGENTS.md`. Do not substitute manual
inspection for automated acceptance. Apply the documented three-attempt
failure-loop rule before requesting focused human feedback.
